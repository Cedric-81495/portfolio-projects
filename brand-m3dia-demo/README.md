# Brand M3dia Demo – Digital Agency Website

> **Status:** In development

A fictional digital agency website built as a portfolio project for a Full-Stack WordPress Developer role. It includes a custom plugin, **Agency Lead Manager**, for lead capture, CRM-style lead management, a REST API, and webhook integration.

## Tech stack

WordPress · Elementor Free · PHP · JavaScript · HTML/CSS · MySQL · WordPress REST API · Git

## Planned features

- Responsive agency site: Home, Services, Portfolio, About, Contact
- Quote calculator (PHP + JavaScript)
- Lead capture form with server-side validation
- Custom MySQL table for leads
- Admin dashboard for managing leads
- Custom REST API endpoints
- Webhook integration with an external CRM

Full documentation (installation, architecture, database schema, API reference, and testing) will be added as features are completed.
